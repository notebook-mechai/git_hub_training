گام ۱:
---------------------------------------------------------------------------------
ورود به پوشه و ساخت مخزن محلی
(Local Repository)
ابتدا یک پوشه در مسیر دلخواه ایجاد می کنیم
و از طریق ترمینال وارد آن پوشه میشویم 



گام 2:
---------------------------------------------------------------------------------
تبدیل یک پوشه معمولی به یک مخزن گیت (شروع پروژه).
git init



گام 3:
---------------------------------------------------------------------------------
یک فایل تحت عنوان کد و  یا هر چیز دیگری را نوشته و درون آن قرار می دهیم



گام 4:
---------------------------------------------------------------------------------
نمایش وضعیت فعلی (کدام فایل‌ها تغییر کرده‌اند و آماده ثبت هستند).
git status



گام 5:
---------------------------------------------------------------------------------
ساخت شاخه جدید
(Branching)
در محیط حرفه‌ای، ما هرگز مستقیماً روی شاخه اصلی
(main یا master)
کد نمی‌زنیم. برای هر ویژگی یا تغییر، یک شاخه جدید می‌سازیم.

git checkout -b feature/hello-world

: توضیحات دستور وارد شده
checkout یعنی جابه‌جایی بین شاخه‌ها.
-b یعنی یک شاخه جدید بساز.
feature/hello-world نام شاخه ماست



گام 6:
---------------------------------------------------------------------------------
افزودن فایل به مرحله آماده‌سازی
(Staging)
حالا باید به گیت بگوییم که تغییرات این فایل خاص را برای ثبت نهایی آماده کند



گام 7:
---------------------------------------------------------------------------------
ثبت نهایی تغییرات
(Commit)

حالا از وضعیت فعلی کد یک "عکس" یا نقطه ذخیره 
(Save Point)
می‌گیریم:
git commit -m "Add C++ Hello World program"



گام 8:
---------------------------------------------------------------------------------
git remote add origin https://github.com/notebook-mechai/git_hub_training.git
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git



گام 9:
---------------------------------------------------------------------------------
وارد سایت گیت  هاب شده و یک مخزن جدید می سازیم



گام 10:
---------------------------------------------------------------------------------
حالا شاخه‌ای که ساخته‌اید و کامیت کرده‌اید را به سرور ابری می‌فرستیم:
git push --set-upstream feature.hello-world feature/hello-world

git push -u origin feature/hello-world




گام 11:
---------------------------------------------------------------------------------
ادغام به شاخه اصلی
(Merge)

ابتدا به شاخه اصلی برگردید
git checkout main

ادغام  شاخه ایجاد شده با شاخه اصلی
git merge feature/hello-world

حالا که شاخه اصلی آپدیت شد، آن را هم به گیت‌هاب بفرستید
git push origin main



مشاهده تمامی شاخه های در گیت
git branch
git log --oneline --decorate --graph --all

مشاهده تمامی شاخه ها در گیت هاب
git branch -a
