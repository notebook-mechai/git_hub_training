برای خارج کردن همه فایل‌ها از حالت آماده‌سازی
Unstage

> git restore --staged .


خارج کردن فقط یک فایل خاص
> git restore --staged main.cpp


خارج کردن یک پوشه خاص
> git restore --staged src/


دیدن وضعیت فعلی
> git status

دیدن تغییرات دقیق
> git diff


همه تغییرات پاک می‌شوند
> git reset --hard


=================================================================
[Working Directory]  →  [Staging Area]  →  [Repository]
    (فایل‌های شما)        (آماده کامیت)       (ثبت شده)
         ↓
    git add . همه را به اینجا آورد
	
=================================================================	
[Working Directory]  ←  [Staging Area]
    (فایل‌های شما)        (خالی شد)
         ↑
    تغییراتتان هنوز اینجاست!
