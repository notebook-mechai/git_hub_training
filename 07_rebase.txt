
فرض کنید شما و دوستتان هر دو در حال نوشتن یک کتاب هستید

مفهوم ادغام
Merge
----------
شما و دوستتان هر کدام فصل‌هایی نوشته‌اید. در پایان، همه فصل‌ها را در یک کتاب بزرگ کنار
هم می‌چینید. تاریخچه مشخص است: "این فصل را من نوشتم، آن فصل را دوستم


مفهوم پایه ریزی مجدد
rebase
----------
شما فصل‌هایتان را نوشته‌اید، اما قبل از نهایی کردن، دوستتان چند فصل جدید اضافه
کرده. شما فصل‌هایتان را برمی‌دارید و دقیقاً بعد از فصل‌های دوستتان قرار می‌دهید، انگار که از اول به ترتیب
نوشته شده‌اند. نتیجه نهایی یک کتاب تمیز و خطی است


> git checkout main
> git merge feature


> git checkout feature
> git rebase main
