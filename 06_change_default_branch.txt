
> git branch -M main


> git branch -m main

این دستور نام شاخه‌ای که الان روی آن هستید را به
main
تغییر می دهد


مثال

> git branch
* master

> git branch -M main

> git branch
* main

توضیحات
-----------------------------------------------------------------------
-m
اگر شاخه‌ای با نام مقصد وجود داشته باشد، خطا می‌دهد و تغییر نام نمی‌دهد


-M
حتی اگر شاخه‌ای با نام مقصد وجود داشته باشد، آن را بازنویسی می‌کند
